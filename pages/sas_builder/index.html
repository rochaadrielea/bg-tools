SAS export builder

SAP · Teamcenter · Opcenter → the export the SAS dashboard eats v3.8 · runs fully offline · nothing leaves this machine
What this does. You load reports. In Merge mode every report contributes rows; rows that share an NC id collapse into one, and later reports fill only the cells the earlier ones left empty — a value is never overwritten. In Join mode one report is the base and the others only add columns onto it. Output is an .xlsx with the exact headers ingest_sas.py expects.
The engine never guesses a value and never invents a link. Duplicate ids inside one file block the build. Every disagreement between two sources is listed, not silently resolved.
